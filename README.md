## 🕹 Ойын механикасы

1. Мұғалім **«🎲 КУБИКТІ ЛАҚТЫР»** батырмасын басады — кубик айналып, 1–6 саны түседі.
2. Фигура **автоматты түрде** клеткадан клеткаға анимациямен жылжиды.
3. Орталық **жасыл шар** сұрақ/тапсырма панеліне айналады.
4. **«👁 ЖАУАБЫ»** → дұрыс жауап көрінеді → **«✅ ДҰРЫС»** немесе **«❌ БҰРЫС»**.
5. Бұрыс жауап = **−1 ❤️** және фигура **START-қа қайтады**.
6. Өмір таусылса команда **ойыннан шығады** (☠️), кезегі өткізіліп отырады.
7. ФИНАЛға бірінші жеткен команда — **жеңімпаз!** 🏆

### 🔴 Қауіпті клеткалар (5, 12, 19, 27)
Физикалық белсенділік тапсырмалары:
- **«Түркі жауынгері»** — 10 рет отырып-тұру (бүкіл команда)
- **«Қалқан ұстаған жауынгер»** — 20 секунд wall sit (таймермен)
- **«Жауынгердің күші»** — 5 рет қолды бүгіп-жазу (жеңілдетілген)
- **«Түрік қағаны»** — 20 секунд бір аяқпен тұру (бүкіл команда)

Сұрақтар **«ТҮРКІ ДӘУІРІ — 60 ТАПСЫРМА»** атты PDF құжаттан алынды және `js/data.js` ішінде сақталған:

## 🖥 Мұғалімге арналған нұсқау

1. Интерактивті тақтада (немесе проекторда) сайтты ашыңыз.
2. **⛶** (FULLSCREEN) батырмасын басып, толық экранға өтіңіз.
3. **«▶ ОЙЫНДЫ БАСТАУ»** → командалар START-та, 5 өмірден.
4. Кезектегі командаға кубик тастатыңыз → сұрақ шығады.
5. Команда жауабын тыңдап, **«ЖАУАБЫ»** басыңыз → дұрыс жауаппен салыстырыңыз.
6. **«✅ ДҰРЫС»** / **«❌ БҰРЫС»** → келесі команда автоматты түрде жалғасады.
7. Команда атауын өзгерту: төменгі тақтадағы **✎** батырмасы немесе атауды басу.

> **Мұғалім фигураны ешқашан қолмен жылжытпайды** — барлығы автоматты: кубик → қозғалыс → сұрақ → жауап → келесі команда.

## 🧩 Техникалық құрылым

```
djumanji/
├── index.html          # Негізгі бет (splash, тақта, панельдер, жеңіс-экран)
├── css/
│   └── styles.css      # Барлық стильдер (16:9, адаптив, анимациялар)
├── js/
│   ├── data.js         # 60 тапсырма + фигуралар + спираль геометриясы
│   ├── sounds.js       # Web Audio дыбыс қозғалтқышы
│   └── game.js         # Ойын логикасы (state, кубик, қозғалыс, өмір, жеңіс)
└── assets/
    └── hero.jpg        # Заставкаға арналған фон (AI-генерация)
```

- **HTML5 + CSS3 + JavaScript** — ешқандай фреймворк, ешқандай сыртқы тәуелділік.
- State құрылымы: әр командада `{ id, name, position, lives, active, figure }`.
- Сұрақтар қайталанбайды (`usedQuestions`), қор таусылса ғана қайта араласады.
